## Project Description

Personal Task Tracker is a simple Laravel web application for organizing daily tasks. Users can create tasks with notes and due dates, view their task list, edit task details, delete tasks, and update each task between pending and completed statuses.

## Database Used

SQLite

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Status

## Technology

- Laravel
- PHP
- Blade templates
- SQLite

## Running the Project

```bash
php artisan migrate
php artisan serve
```

Open `http://127.0.0.1:8000` in a browser.
